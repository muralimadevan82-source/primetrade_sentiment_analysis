# 📊 Primetrade.ai — Bitcoin Sentiment × Trader Behavior Analysis

> **Hiring Assignment | Data Science & Quant Research**  
> Uncovering the relationship between Bitcoin market sentiment and on-chain trader performance on Hyperliquid.

---

## 🔍 Project Overview

This project investigates how Bitcoin's Fear & Greed Index influences real trader behavior on the Hyperliquid perpetuals exchange. Using 211,224 trades from 32 accounts across 2024, we map sentiment regimes to PnL outcomes, risk appetite, symbol selection, and behavioral patterns — producing statistically validated insights and actionable trading strategies.

**Key Question:** Do traders perform better, take more risk, or behave differently when markets are fearful vs greedy?

---

## 📁 Dataset Description

### 1. Bitcoin Fear & Greed Index (`fear_greed_index.csv`)
- **Source:** Alternative.me / CoinMarketCap Sentiment API
- **Coverage:** Feb 2018 – May 2025 (2,644 daily records)
- **Columns:**
  - `timestamp` — Unix epoch
  - `value` — Sentiment score 0–100
  - `classification` — Extreme Fear / Fear / Neutral / Greed / Extreme Greed
  - `date` — Human-readable date

### 2. Hyperliquid Trader Data (`historical_data.csv`)
- **Source:** Hyperliquid on-chain DEX perpetuals data
- **Coverage:** Full year 2024 (211,224 trade records)
- **Columns:**
  - `Account` — Trader wallet address (32 unique accounts)
  - `Coin` — Symbol traded (246 unique)
  - `Execution Price` — Fill price
  - `Size Tokens` / `Size USD` — Position size
  - `Side` — BUY / SELL
  - `Timestamp IST` — Trade timestamp (IST timezone)
  - `Start Position` — Position size before trade
  - `Direction` — Trade direction
  - `Closed PnL` — Realized profit/loss in USD
  - `Transaction Hash` — On-chain tx reference
  - `Fee` — Trading fee paid

## 🏆 Key Insights

| # | Insight | Significance |
|---|---------|-------------|
| 1 | Extreme Greed = 46.5% win rate (highest of all regimes) | +9.4pp vs Extreme Fear |
| 2 | Fear drives 2.5× larger trade sizes ($7,816 vs $3,112) | Behavioral overexposure |
| 3 | Greed zone: higher PnL at lower trade size | Better capital efficiency |
| 4 | Fear zone loss rate is 31% higher than Greed zone | Risk asymmetry confirmed |
| 5 | HYPE generates $1.32M PnL in Fear, $325K in Greed | Regime-specific alpha |
| 6 | Mann-Whitney U test: Fear vs Greed PnL p=0.001 | Statistically significant |
| 7 | @107 generates $2.71M in Greed zones alone | Momentum asset in bull sentiment |
| 8 | Top account: +$2.14M | Bottom: -$167K (same dataset) | Skill vs noise separation |
| 9 | Greed zone: net SELL-heavy (47K SELL vs 42K BUY) | Disciplined profit-taking |
| 10 | Big trades (top 1%) show no win rate improvement | Size ≠ edge |

## 📌 Conclusions

1. **Sentiment is a real alpha signal** — statistically confirmed, not noise
2. **Fear behavior is paradoxically risky** — bigger positions, worse outcomes
3. **Greed is capital-efficient** — same returns, smaller positions
4. **Symbol selection should be sentiment-conditioned** — different assets lead in different regimes
5. **Account-level dispersion is high** — systematic strategies far outperform reactive ones
